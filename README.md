# Fine-Particulate-Matter-PM2.5-Concentration-Forecasting-Dashboard
Real-time PM2.5 air quality forecasting pipeline &amp; Streamlit dashboard integrating OpenWeather API feeds and US EPA AQI health advisories. Benchmarked Ridge, Random Forest, XGBoost, and LightGBM on 43,800+ hourly records using leakage-free chronological splits and hybrid imputation. (In Progress)
